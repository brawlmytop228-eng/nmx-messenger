# NMX Messenger 5.0

Полноценный веб-мессенджер: регистрация с паролем, личные чаты и группы,
медиа/файлы любого размера, реакции, ответы, редактирование, typing,
read-чеки, WebRTC-звонки.

## Что нового
- **Пароли** (scrypt + соль) и регистрация/логин через HTTP API
- **Группы**: создание, добавление/удаление участников, выход
- **Список чатов** с превью, временем, счётчиком непрочитанных
- **Загрузка файлов без ограничений** — стрим на диск, размер ограничен только диском
- **Красивый адаптивный UI**: сайдбар + чат, на мобильном — выезжающие панели
- **Реакции**, ответы, редактирование, удаление, разделители по дням
- **Typing-индикатор**, онлайн-статусы, read-чеки (✓ / ✓✓)
- **Голосовые сообщения** через MediaRecorder
- **Image/video viewer** по клику

## Render
Build: `npm install`
Start: `npm start`

## Переменные окружения (для звонков)
- `TURN_URL`
- `TURN_USERNAME`
- `TURN_CREDENTIAL`

## Файлы
- `public/index.html` — фронтенд
- `public/bird.jpg` — логотип/дефолтный аватар (замени на своё)
- `data.json` — база (создаётся автоматически)
- `public/uploads/` — загруженные файлы
